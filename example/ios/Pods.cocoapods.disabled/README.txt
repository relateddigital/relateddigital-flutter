This folder is a placeholder, not a CocoaPods install.

The example app is Swift Package Manager only. A directory named `Pods/` (and `Pods/Pods.xcodeproj`) can make Xcode mix CocoaPods with SPM.

To test CocoaPods later:
1. Rename `Podfile.cocoapods` → `Podfile`
2. Run `pod install` in this directory
3. That generates `Pods/` locally (gitignored)
